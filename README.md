# Jarvis 2.0 — помощник для Windows

Разговор на русском, голос и управление компьютером из одной панели. Напишите просьбу, нажмите **Говорить** или используйте **Ctrl+Alt+Space** из другого приложения.

## Запустить

- Готовая версия: `dist\Jarvis\Jarvis.exe`.
- Один переносимый файл: `dist\Jarvis-2.0.exe`.
- Из исходников на этом компьютере: двойной клик по `run.bat`.
- Новое окружение: установите Python 3.14, затем запустите `setup.bat`.

Панель разговора открывается сразу. Повторный запуск показывает уже работающий Jarvis. Ошибка микрофона не закрывает окно: текстовый чат продолжает работать.

## Как пользоваться

| Действие | Управление |
| --- | --- |
| Написать просьбу | Поле в разделе «Разговор», затем Enter |
| Говорить без имени | Кнопка «Говорить» или Ctrl+Alt+Space |
| Открыть разговор | Клик по плашке или Ctrl+Alt+J |
| Остановить голос и следующие шаги | «Стоп» или Ctrl+Alt+X |
| Пауза микрофона | Ctrl+M в панели или контекстное меню плашки |
| Начать новый разговор | Кнопка «Новый» |
| Закрыть Jarvis | «Выход» внизу панели |

Для голосового обращения в фоне скажите **«Джарвис, …»**. Русское имя определяется локальным Whisper. Тишина завершает голосовую сессию, но история разговора остаётся в памяти процесса. После явной активации может использоваться разрешённое облачное распознавание; режим `private` использует только локальное. Озвучка Edge TTS — отдельный сетевой сервис.

Чтобы напечатать текст в другой программе, сначала выберите её окно, затем откройте Jarvis через Ctrl+Alt+J. Исходное окно сохраняется для команды. После открытия новой программы помощник проверяет фокус перед вводом. Мышь и прокрутка требуют указатель над целевым окном; удобнее давать такие команды голосом.

## Примеры

- «Сколько времени?»
- «Какие окна открыты?»
- «Открой блокнот и напечатай Привет, мир!»
- «Переключись на окно Блокнот»
- «Напечатай Hello, World! Это мой текст.»
- «Нажми ctrl+a»
- «Открой загрузки»
- «Установи громкость на сорок»
- «Добавь заметку купить кабель»
- «Напомни через десять минут про перерыв»
- «Поставь таймер на пять минут»
- «Включи диктовку» … «Стоп диктовка»
- «Найди в интернете погоду в Ташкенте»
- «Объясни простыми словами, как работает электродвигатель»

Последний пример требует доступного AI. Основные команды Windows, заметки, таймеры и напоминания работают локально. Доступные действия перечислены во вкладке «Навыки».

Для срабатывания таймера или напоминания Jarvis должен оставаться запущенным. Уведомление появляется в разговоре и сопровождается системным звуковым сигналом.

## Что изменилось

Вместо выполнения во время поиска совпадения Jarvis сначала разбирает просьбу в план до восьми шагов, проверяет параметры и выполняет шаги по очереди. Невыполненный шаг останавливает остальную цепочку. Ответ отражает результат Windows, а не обещание модели.

Исправлены ложные действия по словам «добавь» и «яркость», потеря регистра/пунктуации в печати, повторное выполнение после TypeError, COM в фоновых потоках, отказ русского wake, пропуск команды при долгом распознавании и потеря контекста. Подтверждение связано с конкретным запросом, исходным окном и положением указателя; двойной клик не разрешает следующий запрос.

Чат, голос и диагностика используют один рабочий поток исполнения. UI остаётся доступен при сетевой ошибке. Отмена останавливает воспроизведение сразу и проверяется перед следующими шагами. Уже начатый сетевой запрос заканчивается по ответу или таймауту; отменённый ответ не вызывает новые действия.

## AI и голос

Во вкладке **AI Pool** можно указать собственный ключ Groq, Cerebras, Gemini, OpenRouter или Claude. Поддерживается также Ollama: нужен отдельно запущенный сервер на `localhost:11434` и установленная выбранная модель. На этом компьютере проверен Gemini с моделью `gemini-3.6-flash`; прежняя модель вернула ошибку 404. Доступность и лимиты зависят от аккаунта провайдера. Ключи в сборку не включаются.

Русский голос по умолчанию — Edge TTS Dmitry. Для него нужен интернет. При сетевой ошибке используется совместимый голос Windows, если он установлен; отсутствие подходящего голоса показывается в панели, текстовый ответ остаётся. На проверенном компьютере русского офлайн-голоса Windows нет.

Локальные модели речи устанавливаются явно через `prepare-voice.bat`. На этом компьютере используемые модели уже есть. Для EXE без исходников: `Jarvis-2.0.exe --prepare-voice` (прогресс записывается в журнал). Проверка кеша из исходников: `.venv\Scripts\python.exe -m core.prepare_voice --check`.

Выбор микрофона, голоса и моделей применяется через рабочую очередь. Тема и цвет обновляются при следующем запуске.

## Данные

Единый профиль исходников и EXE:

```text
%LOCALAPPDATA%\Jarvis\settings.env   настройки без ключей
%LOCALAPPDATA%\Jarvis\secrets.json   ключи под защитой Windows DPAPI
%LOCALAPPDATA%\Jarvis\jarvis.db      заметки, напоминания, навыки и журнал
%LOCALAPPDATA%\Jarvis\jarvis.log     диагностика процесса
```

Настройки старого `.env` переносятся в профиль при первом запуске новой версии. История разговора в новой панели хранится в памяти процесса, до 200 сообщений; контекст AI — последние 24 сообщения. Запись микрофона не сохраняется в базу. Синтезированные фразы могут кешироваться локально.

## Диагностика и разработка

```powershell
.\.venv\Scripts\python.exe jarvis.py --check
.\.venv\Scripts\python.exe jarvis.py --mics
.\.venv\Scripts\python.exe jarvis.py --text-only
.\.venv\Scripts\python.exe jarvis.py --console
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

`--check` читает устройства и проверяет AI, без записи микрофона и озвучивания. Для проверки реальной речи используйте кнопки во вкладке «Диагностика». `--text-only` открывает обычное приложение с микрофоном на паузе; кнопка «Говорить» активирует его.

`build-exe.bat` собирает каталог с EXE, `build-single-exe.bat` — один файл. Для сборки нужен PyInstaller (`python -m pip install pyinstaller`). Скрипты останавливаются при ошибке тестов или упаковки.

Архитектура и воспроизводимые проверки: [.design/jarvis-rebuild/PLAN.md](.design/jarvis-rebuild/PLAN.md).

## Практические границы

Jarvis выполняет зарегистрированные действия Windows и планы из них. Самостоятельного понимания произвольных кнопок по изображению экрана и универсального управления любым сайтом в этой версии нет. Доступ к почте, календарю и умному дому требует отдельных интеграций. Администраторские окна Windows могут отклонить обычный ввод. При недоступном AI свободный разговор ограничен, но локальные команды остаются доступны.
